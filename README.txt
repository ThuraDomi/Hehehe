FLOWER MAIL SURPRISE WEBSITE

How to run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser.
4. For the best experience, use the Live Server extension.

Sequence:
- Space background with white twinkling stars
- Pink envelope with "Open Me" button
- Envelope opens
- Colorful flowers burst from the envelope
- Flowers spread across the screen
- Flowers clear
- Neon "Surprise" appears

Files:
- index.html
- style.css
- script.js

You can change the text "Surprise" inside index.html.


This version is optimized for mobile phones and touch screens.
